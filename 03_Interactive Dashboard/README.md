The Singapore Port AIS Traffic & Congestion Analysis Dashboard is a Tableau-based executive suite for real-time monitoring of port performance. The dashboard features an interactive geospatial map that color-codes AIS Activities by status—Anchor, Moored, Underway, or Special—to identify saturation zones and active transit fairways.
